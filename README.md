# 🎵 Music Library Management System

A **DBMS Capstone Project** developed using MySQL 8.0 to manage artists, albums, tracks, genres, users, playlists, and listening history.

## 🛠️ Technologies
- MySQL 8.0
- MySQL Workbench
- SQL

## 📂 Database Tables
`artists`, `albums`, `tracks`, `genres`, `users`, `playlists`, `playlist_tracks`, `play_history`

## 🚀 Features
- CRUD operations (Create, Read, Update, Delete)
- Search songs by artist, title, and genre
- Playlist creation and management
- Listening history analysis
- Primary and foreign key constraints
- B-tree, FULLTEXT, and composite indexes
- SQL views and joins
- Query optimization using EXPLAIN
- Window functions: DENSE_RANK, LEAD, SUM OVER

## ▶️ How to Run
1. Open MySQL Workbench.
2. Import `music_library_script(2).sql`.
3. Execute the setup and queries in order.
4. View the result grids.

**Note:** Initial setup deletes any existing `music_library` database.
